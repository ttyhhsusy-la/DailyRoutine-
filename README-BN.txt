আমার ডেইলি রুটিন — Android WebView project

APK তৈরির সহজ উপায়:
1. GitHub-এ নতুন repository তৈরি করে এই ZIP-এর সব ফাইল upload করুন।
2. Repository-এর Actions tab-এ যান।
3. “Build Daily Routine APK” workflow নির্বাচন করুন এবং Run workflow চাপুন।
4. কাজ শেষ হলে workflow run-এর Artifacts থেকে DailyRoutine-debug-apk ডাউনলোড করুন।
5. ZIP extract করে app-debug.apk ফোনে ইনস্টল করুন।

নোট: এটি debug APK; ইনস্টল করার সময় Android-এর অনুমতি চাইতে পারে।
